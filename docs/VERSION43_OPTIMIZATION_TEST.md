# 버전 43 최적화 테스트

## 기준

- 운영 기준: Apps Script 배포관리 `디자인v2` 버전 43
- GitHub 기준 브랜치: `version43-optimization`
- 운영 `main`과 배포 버전 43은 변경하지 않는다.

## 이번 최적화 범위

- 브랜드 운영센터 집계 시 직원 파일 건수를 브랜드마다 전체 검색하지 않는다.
- 파일 목록을 한 번 순회해 브랜드 코드별 건수 인덱스를 만든다.
- 데이터 결과, 저장 방식, 권한, 캐시 정책은 변경하지 않는다.
- 서버 캐시는 이번 브랜치에 추가하지 않는다.

## 필수 회귀 테스트

1. 브랜드 목록 수와 브랜드 코드가 버전 43과 동일하다.
2. 각 브랜드의 상품 수, 파일 수, 검수 건수, 보완 건수가 동일하다.
3. 브랜드 상세의 개요·상품·재고·영업 활동·파일 탭이 정상적으로 열린다.
4. 브랜드 수정 후 즉시 최신 값이 조회된다.
5. 상담 기록 추가 및 후속 업무 완료가 정상 동작한다.
6. 간편 입출고 저장과 재고 계산 결과가 동일하다.
7. 파트너 화면과 상품 제출 기능에 변화가 없다.
8. `testBrandWorkspace`, `testBrandCommerce`, `testStaffPerformance`가 모두 통과한다.

## 성능 확인

- `getBrandWorkspace()` 실행시간을 버전 43과 각각 3회 측정한다.
- 첫 실행과 연속 실행을 구분해 기록한다.
- 반환된 브랜드별 `fileCount`가 버전 43과 완전히 동일한지 비교한다.

## 승격 조건

- 기능 결과 차이 없음
- 세 테스트 함수 모두 통과
- 브랜드 파일 건수 불일치 없음
- 평균 실행시간이 악화되지 않음

조건을 만족할 때만 `main`에 병합하고 새로운 Apps Script 버전으로 배포한다.
